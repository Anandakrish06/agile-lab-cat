# Weather Monitoring System

## Project Description
A weather monitoring system that allows users to search for
weather information and view current weather and forecasts.

## Features
- User login
- Search weather by location
- View current weather
- View weather forecast
- Weather alerts

## Technologies Used
- Python
- Weather API
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Install requirements.
3. Run app.py.

## Use Cases
1. User Login
2. Search Weather
3. View Current Weather
4. View Forecast
5. Weather Alerts
